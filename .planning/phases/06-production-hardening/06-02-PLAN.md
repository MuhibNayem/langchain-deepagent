```python
from dataclasses import dataclass, field
from datetime import datetime
from typing import Any, Optional

@dataclass
class DecisionPoint:
    """A key decision made during harness execution."""
    decision_id: str
    timestamp: datetime
    phase: str  # e.g., "iteration", "evaluation", "sprint"
    decision_type: str  # e.g., "quality_gate", "convergence", "tool_selection"
    context: dict[str, Any]  # inputs to the decision
    choice: str  # what was chosen
    alternatives: list[str]  # what else was considered
    rationale: str  # why this was chosen
    outcome: Optional[str] = None  # what resulted (filled later)

@dataclass
class TraceEntry:
    """A single step in the harness execution trace."""
    entry_id: str
    timestamp: datetime
    step_number: int
    component: str  # which component (planner, evaluator, executor, etc.)
    action: str  # what action was taken
    inputs: dict[str, Any]
    outputs: dict[str, Any]
    decisions: list[DecisionPoint] = field(default_factory=list)
    metadata: dict[str, Any] = field(default_factory=dict)
```

Create `DecisionLogger` class:
- `log_decision(point: DecisionPoint)` — records a decision
- `log_trace_entry(entry: TraceEntry)` — records a trace entry
- `get_trace_for_task(task_id: str) -> list[TraceEntry]` — retrieves trace
- `annotate_decision_outcome(decision_id: str, outcome: str)` — fills in outcome

Store traces in Redis using the same key pattern as checkpointer. Key format: `trace:{task_id}`.

```python
class TraceViewer:
    """View and replay harness execution traces."""

    def __init__(self, redis_client=None):
        # Use existing checkpointer's Redis client if available
        self.redis = redis_client

    def get_trace(self, task_id: str) -> list[TraceEntry]:
        """Retrieve full trace for a task."""

    def replay_trace(self, task_id: str) -> ReplayResult:
        """Reconstruct execution path from checkpoints.
        Returns ReplayResult with decisions_reconstructed and execution_path.
        """

    def export_trace(self, task_id: str, format: str = "json") -> str:
        """Export trace as JSON or human-readable text."""

    def compare_traces(self, task_id_a: str, task_id_b: str) -> list[str]:
        """Compare two traces, highlighting differences in decisions."""
```

The `replay_trace()` method should:
1. Fetch all TraceEntry records for the task from Redis
2. Reconstruct the decision chain from DecisionPoint records
3. Return a ReplayResult with `decisions_reconstructed` and `execution_path`
4. Handle missing entries gracefully — partial traces still replayable
