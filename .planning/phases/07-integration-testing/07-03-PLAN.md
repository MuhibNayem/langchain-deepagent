       - Compare current vs baseline
       - Identify statistically significant drops (> 5% in any category)

    RegressionReport dataclass:

    - summary: str
    
    Severity thresholds:
    - CRITICAL: > 20% drop
    - HIGH: > 10% drop
    - MEDIUM: > 5% drop
