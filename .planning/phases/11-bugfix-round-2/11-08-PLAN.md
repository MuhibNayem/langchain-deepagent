From luminamind/execution/task_pool.py _execute_task (lines 72-80):
```python
if task.timeout:
    import signal
    signal.alarm(int(task.timeout))  # UNIX only!

result = task.func(*task.args, **task.kwargs)

if task.timeout:
    signal.alarm(0)  # Cancel alarm
```

Problems:
1. signal.alarm is not available on Windows (use threading.Event instead)
2. Using signal.alarm in a thread affects the main thread unexpectedly
3. Should use concurrent.futures.TimeoutFuture or threading.Timer instead
