From luminamind/plugins/sandbox.py lines 32-33:
```python
async with Sandbox(config) as sandbox:
    result = await sandbox.execute(plugin_code, language="python")
```

But Sandbox (from luminamind/sandbox/sandbox.py) is an ABC:
```python
class Sandbox(ABC):
    @abstractmethod
    async def start(self) -> str: ...
```

The fix should use DockerBackend (concrete implementation) instead of Sandbox.
</context>

```python
class DockerBackend(Sandbox):
    """Docker-based sandbox backend."""
    async def start(self) -> str: ...
    async def execute(self, code: str, language: str = "python") -> SandboxResult: ...
    async def stop(self) -> None: ...
    async def get_status(self) -> SandboxStatus: ...
    async def write_file(self, path: str, content: str) -> None: ...
    async def read_file(self, path: str) -> str: ...
```
</interfaces>
